# Changelog

The changes of each version are in the notes of its [GitHub release](https://github.com/hectorespert/jmediasoup/releases), whose tag is the version, `X.Y.Z`. Each version is on [Maven Central](https://central.sonatype.com/artifact/io.github.hectorespert/jmediasoup) as `io.github.hectorespert:jmediasoup`.

The project follows [Semantic Versioning](https://semver.org): before `1.0.0`, a minor version can break the API.
