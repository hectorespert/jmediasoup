## Project state

Freshly generated by `gradle init`: there is no jmediasoup code yet. `org.example.Library`, its test, and the `commons-math3` and `guava` dependencies are all template placeholders, so don't treat them as project conventions or as a real API.

## Commands

Use the Gradle wrapper (Gradle 8.14.4). There is one subproject, `lib`.

```bash
./gradlew build                  # compile, test and assemble the jar
./gradlew test                   # run all tests
./gradlew :lib:test --tests 'org.example.LibraryTest.someLibraryMethodReturnsTrue'   # run a single test
./gradlew clean
```

No linter or formatter is configured. Test reports are written to `lib/build/reports/tests/test/`.

## Build setup

- Java 21 through a Gradle toolchain (`lib/build.gradle.kts`). The foojay resolver plugin downloads a matching JDK if none is installed.
- Tests use JUnit 5 (Jupiter).
- Declare dependency versions in the version catalog, `gradle/libs.versions.toml`, and reference them as `libs.*` from the build script.
- The `java-library` plugin is applied, so `api` dependencies are exposed to consumers and `implementation` dependencies are not.
- The configuration cache is on (`gradle.properties`), so custom tasks and build logic have to be compatible with it.
